# How to build this manuscript

Target journal: **BMC Microbiology** (ISSN 1471-2180), Springer Nature.
Document class: `sn-jnl.cls` v3.1 (December 2024), class option
`sn-vancouver-num`.

## Quick start

Linux / macOS / this HPC cluster:

```bash
export PATH="$HOME/.TinyTeX/bin/x86_64-linux:$PATH"
latexmk -pdf manuscript.tex
```

Output: `manuscript.pdf`. `latexmk` re-runs `pdflatex` and `bibtex` until the
cross-references, citations and page numbers settle, so a single command is
enough.

Windows:

```powershell
.\build.ps1
```

## Manual build (if you do not have latexmk)

```bash
pdflatex manuscript.tex
bibtex   manuscript
pdflatex manuscript.tex
pdflatex manuscript.tex
```

## What is in this directory

| File | Purpose |
|---|---|
| `manuscript.tex` | The manuscript |
| `sn-jnl.cls` | Springer Nature class, v3.1 |
| `sn-vancouver-num.bst` | Vancouver numbered bibliography style, v1.1 |
| `reference.bib` | **Generated** — see below |
| `tables/table_pipeline_summary.tex` | **Generated** — see below |
| `Fig/` | Figure PDFs |
| `make_reference_bib.py` | Regenerates `reference.bib` |

`reference.bib` is generated from
`../paper/publication/submission_readiness/references_source/bibliography.json`
by `make_reference_bib.py`. Do not hand-edit it; re-run the script instead.

`tables/table_pipeline_summary.tex` is generated by
`../src/scripts/figures/make_pipeline_summary_table.py` from the claims
register. Row labels are subject to author review; the caption is written in
`manuscript.tex`.

`sn-vancouver-num.bst` sits at the top level on purpose: Editorial Manager
strips subdirectories from a LaTeX bundle, so a `bst/` folder would lose it.

## Things worth knowing about this class

- **The class sets the bibliography style itself.** The `sn-vancouver-num`
  option loads `natbib` in numerical mode and issues
  `\bibliographystyle{sn-vancouver-num}`. Do not add another
  `\bibliographystyle` and do not pass options to `natbib` before
  `\documentclass` — LaTeX aborts with `Illegal, another \bibstyle command`.
- **Do not load `booktabs`.** `sn-jnl` defines its own `\toprule`, `\midrule`
  and `\botrule`; `booktabs` clashes with them.
- **ORCID icons need a workaround.** `sn-jnl` pre-defines `\orcidlogo` to
  expect an `Orcidlogo.eps` we do not ship. Undefine it *before* loading
  `orcidlink`, exactly as the preamble does:
  ```latex
  \makeatletter\let\orcidlogo\@undefined\makeatother
  \usepackage{orcidlink}
  ```
- **Front matter uses the starred forms.** `\author*[1]{...}` marks the
  corresponding author; `\email{}` follows it. Affiliations use
  `\affil*[1]{\orgdiv{}\orgname{}\orgaddress{\street{}\city{}\postcode{}\state{}\country{}}}`.
- **Citations:** `\cite{a,b}`; never `\citet`/`\citep` (author–year commands).
- **Abstract:** structured, headed Background / Results / Conclusions, at most
  350 words, no citations, equations or cross-references. Currently 314 words.
- **Keywords:** supplied once through a single `\keywords{...}`. The old
  bracketed form `\keywords[Abbreviations]{...}` this journal does not use is
  gone; BMC wants 3–10 plain keywords.
- **Declarations:** the `\backmatter` block after Limitations holds the BMC
  declaration headings in BMC order (ethics, consent, availability of data and
  materials, competing interests, funding, authors' contributions,
  acknowledgements, then the generative-AI declaration).
- **Submission copy with line numbers:** swap the `\documentclass` line for
  `\documentclass[referee,lineno,pdflatex,sn-vancouver-num]{sn-jnl}`.
- **Do not invent journal metadata.** BMC fills in volume, DOI, submission and
  acceptance dates during production; the previous template's `\DOI`, `\vol`,
  `\received` and similar placeholders have been removed rather than filled
  with guesses.

## Package requirements

The build needs `orcidlink`, `hyperref` (loaded by the class), `graphicx`,
`amsmath`, `amssymb`, `amsfonts`, `amsthm`, `xcolor` and `textcomp`. Under
TinyTeX, install any missing one with:

```bash
tlmgr install orcidlink
```

## Retired Oxford University Press assets

This directory used to build against `oup-authoring-template.cls` for

template and its documentation were removed on 2026-11-10; they remain
recoverable from git history if a build against the old template is ever
