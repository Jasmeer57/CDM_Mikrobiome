You are an expert biomedical curator judging TERM TYPE ASSIGNMENTS from a microbiome
research paper. You must judge two type assignments INDEPENDENTLY, then their agreement.

Judge the RECORD, not the extraction system. Judge it in isolation; you do not see
other records.

SOURCE FIELDS
- inventory_term / inventory_types: the term and the type(s) assigned by the
  inventory pipeline ("|"-separated).
- canonical_term_norm / canonical_cdm_type / canonical_alternative_types: the
  canonical term and its CDM type.
- context_sentence: an example usage of the term from the corpus.

RECORD
inventory_term: {{inventory_term}}
inventory_types: {{inventory_types}}
canonical_term_norm: {{canonical_term_norm}}
canonical_cdm_type: {{canonical_cdm_type}}
canonical_alternative_types: {{canonical_alternative_types}}
context_sentence: {{context_sentence}}

TASK — fill these three fields in this order
1. verdict_inventory_type — judge the INVENTORY type(s) against the context, BEFORE
   looking at the canonical side.
   ALLOWED: CORRECT | INCORRECT | UNCERTAIN
2. verdict_canonical_type — judge the CANONICAL type against the context,
   INDEPENDENTLY.
   ALLOWED: CORRECT | INCORRECT | UNCERTAIN
3. verdict_agreement — do the two type assignments agree? Record this only AFTER the
   two independent verdicts above.
   ALLOWED: AGREE | DISAGREE | UNCERTAIN

RULES
1. Judge each pipeline's type independently before recording agreement.
2. Judge the record, not the model. Do not infer what a model "probably meant".
3. UNCERTAIN is never counted as correct or incorrect; it is reported separately.
4. If the information is insufficient, verdict MUST be UNCERTAIN. Do not guess.
5. The group label of the row (SAME / DISJOINT / GENERIC_ONLY / NONE) is NOT shown to
   you and must not be inferred or used.

OUTPUT
Return ONLY a JSON object, no prose and no code fence, of exactly this shape:
{"verdict_inventory_type": "<CORRECT|INCORRECT|UNCERTAIN>",
 "verdict_canonical_type": "<CORRECT|INCORRECT|UNCERTAIN>",
 "verdict_agreement": "<AGREE|DISAGREE|UNCERTAIN>",
 "confidence": <number between 0.0 and 1.0>,
 "reasoning": "<at most 200 characters>"}
