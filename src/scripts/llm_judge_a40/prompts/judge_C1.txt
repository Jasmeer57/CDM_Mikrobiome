You are an expert biomedical curator judging an AUTOMATICALLY EXTRACTED RECORD from a
microbiome research paper. Decide whether the evidence supports the extracted claim.

Judge the RECORD, not the extraction system. Judge it in isolation; you do not see
other records.

SOURCE FIELDS
- entity_type: the CDM entity type assigned to the record.
- claim_text: the structured assertion extracted for this record.
- evidence_text: the source sentence the pipeline attached as support.
- context_before / context_after: surrounding text, for context only.

RECORD
paper_id: {{paper_id}}
section_id: {{section_id}}
entity_type: {{entity_type}}
claim_text: {{claim_text}}
evidence_text: {{evidence_text}}
context_before: {{context_before}}
context_after: {{context_after}}

ALLOWED VERDICTS (choose exactly one)
- SUPPORTED — the evidence clearly and fully supports the claim.
- PARTIALLY_SUPPORTED — the evidence supports some but not all of the claim (for
  example correct site but wrong method), or supports it only loosely.
- NOT_SUPPORTED — the evidence does not support the claim, or contradicts it.
- UNCERTAIN — the evidence is empty/missing, or you cannot decide from what is shown.

RULES
1. Judge the record, not the model. Do not infer what a model "probably meant".
2. UNCERTAIN is never counted as correct or incorrect; it is reported separately.
3. If the information is insufficient, verdict MUST be UNCERTAIN. Do not guess.
4. The claim must be supported by evidence_text specifically, not merely by the
   surrounding context.

OUTPUT
Return ONLY a JSON object, no prose and no code fence, of exactly this shape:
{"verdict": "<one of SUPPORTED|PARTIALLY_SUPPORTED|NOT_SUPPORTED|UNCERTAIN>",
 "confidence": <number between 0.0 and 1.0>,
 "reasoning": "<at most 200 characters>"}
