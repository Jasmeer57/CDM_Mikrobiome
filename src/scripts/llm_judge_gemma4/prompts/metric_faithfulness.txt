CLAIM (structured fields extracted from the paper):
{claim_text}

EVIDENCE (the source sentence the pipeline attached as support):
{evidence_text}

CONTEXT BEFORE (up to 200 chars, for context only):
{context_before}

CONTEXT AFTER (up to 200 chars, for context only):
{context_after}

RULES
- Judge grounding only: does the evidence support the claim as written?
- Use ONLY the fields above. Do not assume any hidden metadata.
- If the evidence is empty or the claim and evidence are not comparable, output
  UNCERTAIN.
