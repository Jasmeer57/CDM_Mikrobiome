# Table 1. Microbiome-CDM entity types and relation types

| Type | Description | Example entities |
|---|---|---|
| ORGANISM | Bacteria, archaea, fungi, eukaryotes | *Faecalibacterium prausnitzii*, *Akkermansia muciniphila* |
| CHEMICAL | Small molecules, drugs, metabolites | butyrate, infliximab, trimethylamine n-oxide |
| DISEASE | Human diseases and conditions | *inflammatory bowel disease*, *type 2 diabetes mellitus* |
| GENOMICS | Genomics concepts, sequencing approaches | metagenomics, 16S rRNA gene sequencing, whole-genome sequencing |
| PROTEIN | Proteins, enzymes | NOD2 protein, IL-10 |
| DNA_RNA | DNA/RNA elements | 16S rRNA, whole-genome sequencing |
| CELL_TYPE | Cell types | intestinal epithelial cell |
| PATHWAY | Biological pathways | SCFA biosynthesis |
| LAB_METHOD | Lab techniques | 16S rRNA sequencing, shotgun metagenomics |
| DATA_ANALYSIS | Statistical/computational methods | Shannon diversity, alpha-diversity |
| SAMPLE_METHOD | Sample collection | fecal sample collection, biopsy |
| CLINICAL | Clinical metrics | BMI, disease activity index |
| EXPERIMENTAL_METHOD | Experimental design | randomized controlled trial |
| STUDY_DESIGN | Study structure | cohort study, case-control |

**Relation types** (14): `associated_with`, `treats`, `treated_by`, `produces`, `produced_by`, `disrupts`, `depleted_in`, `enriched_in`, `co_occurs_with`, `encodes`, `expresses`, `part_of_pathway`, `participates_in`, `implicated_in`.
