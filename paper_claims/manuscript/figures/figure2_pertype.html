The empirical case for the hybrid

LLM vs spaCy union on normalized, filtered terms (50 papers):
  Jaccard = 0.085
  shared   = 503
  LLM-only = 1,061
  spaCy-only = 4,359
  total distinct = 5,923     ← only ~8.5% shared

Type complementarity:
  LLM-only types:   8  (DATA_ANALYSIS, PATHWAY, LAB_METHOD, SAMPLE_METHOD,
                        EXPERIMENTAL_METHOD, CLINICAL, GENOMICS, STUDY_DESIGN)
  spaCy-only types: 1  (UNKNOWN — untyped residue)
  shared types:      6  (ORGANISM, CHEMICAL, DISEASE, PROTEIN, DNA_RNA, CELL_TYPE)
  missing in both:   0

Why hybrid? Three empirical facts.

1. The two methods are largely disjoint. Only 8.5% of the union of normalized terms is shared between the LLM and spaCy. 1,061 of 1,564 LLM entities (68%) appear in NO spaCy model; 4,359 of 4,862 spaCy entities (90%) appear in NO LLM output.

2. The LLM produces 8 CDM types that no spaCy model produces. These are the higher-level, context-dependent types (DATA_ANALYSIS, PATHWAY, LAB_METHOD, SAMPLE_METHOD, EXPERIMENTAL_METHOD, CLINICAL, GENOMICS, STUDY_DESIGN). spaCy's label set is general (CHEMICAL, DISEASE, CELL_TYPE, etc.) and does not include them.

3. All 14 CDM types are covered. The LLM covers all 14 types; spaCy covers 6 biological types plus UNKNOWN. No CDM type is missing from both methods — the hybrid achieves complete type coverage.
